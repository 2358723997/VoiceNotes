## VoiceNotes后端设计与接口文档

### 1. 项目概述

VoiceNotes是一款语音笔记应用，支持录音、语音转文字、笔记管理等功能。后端系统负责处理录音数据的存储、音频文件管理和语音转文字服务集成。

### 2. 技术栈选择

* **语言**: Python 3.10+

* **Web框架**: FastAPI (高性能异步框架)

* **数据库**: PostgreSQL (生产环境) / SQLite (开发环境)

* **ORM**: SQLAlchemy 2.0

* **音频存储**: 本地文件系统 + 阿里云OSS/Amazon S3 (可选)

* **大模型API**: OpenAI Whisper API (语音转文字)

* **认证**: JWT Token (未来扩展用户系统)

### 3. 数据模型设计

#### 3.1 VoiceRecord模型

```python
class VoiceRecord(Base):
    __tablename__ = "voice_records"
    
    id: Mapped[str] = mapped_column(primary_key=True)
    title: Mapped[str]
    audio_url: Mapped[str]  # 音频文件URL
    text: Mapped[Optional[str]] = mapped_column(nullable=True)
    duration: Mapped[float]  # 录音时长（秒）
    created_at: Mapped[datetime] = mapped_column(default=func.now())
    updated_at: Mapped[datetime] = mapped_column(default=func.now(), onupdate=func.now())
    is_transcribed: Mapped[bool] = mapped_column(default=False)
    transcription_status: Mapped[str] = mapped_column(default="not_started")
    user_id: Mapped[Optional[str]] = mapped_column(nullable=True)  # 未来支持用户系统
```

### 4. API接口设计

#### 4.1 录音管理接口

##### 4.1.1 获取录音列表

* **URL**: `/api/records`

* **方法**: `GET`

* **查询参数**:

  * `page`: 页码，默认1

  * `limit`: 每页数量，默认10

  * `search`: 搜索关键词（标题）

* **响应**:

  ```json
  {
    "total": 100,
    "records": [
      {
        "id": "uuid",
        "title": "录音标题",
        "audio_url": "https://example.com/audio.mp3",
        "duration": 120.5,
        "created_at": "2025-11-28T10:00:00Z",
        "is_transcribed": true,
        "transcription_status": "completed"
      }
    ]
  }
  ```

##### 4.1.2 获取录音详情

* **URL**: `/api/records/{record_id}`

* **方法**: `GET`

* **响应**:

  ```json
  {
    "id": "uuid",
    "title": "录音标题",
    "audio_url": "https://example.com/audio.mp3",
    "text": "转写的文字内容",
    "duration": 120.5,
    "created_at": "2025-11-28T10:00:00Z",
    "updated_at": "2025-11-28T10:05:00Z",
    "is_transcribed": true,
    "transcription_status": "completed"
  }
  ```

##### 4.1.3 创建录音记录

* **URL**: `/api/records`

* **方法**: `POST`

* **请求体**:

  ```json
  {
    "title": "录音标题",
    "audio_url": "https://example.com/audio.mp3",
    "duration": 120.5
  }
  ```

* **响应**:

  ```json
  {
    "id": "uuid",
    "title": "录音标题",
    "audio_url": "https://example.com/audio.mp3",
    "text": null,
    "duration": 120.5,
    "created_at": "2025-11-28T10:00:00Z",
    "updated_at": "2025-11-28T10:00:00Z",
    "is_transcribed": false,
    "transcription_status": "not_started"
  }
  ```

##### 4.1.4 更新录音标题

* **URL**: `/api/records/{record_id}/title`

* **方法**: `PUT`

* **请求体**:

  ```json
  {
    "title": "新的录音标题"
  }
  ```

* **响应**: 更新后的录音详情

##### 4.1.5 删除录音

* **URL**: `/api/records/{record_id}`

* **方法**: `DELETE`

* **响应**:

  ```json
  {
    "message": "录音已成功删除"
  }
  ```

#### 4.2 音频文件接口

##### 4.2.1 上传音频文件

* **URL**: `/api/audio/upload`

* **方法**: `POST`

* **请求体**: `multipart/form-data`

  * `file`: 音频文件（支持m4a、mp3格式）

* **响应**:

  ```json
  {
    "audio_url": "https://example.com/audio/recording_uuid.m4a",
    "file_name": "recording_uuid.m4a"
  }
  ```

##### 4.2.2 下载音频文件

* **URL**: `/api/audio/{file_name}`

* **方法**: `GET`

* **响应**: 音频文件流

#### 4.3 语音转文字接口

##### 4.3.1 提交转写任务

* **URL**: `/api/transcribe`

* **方法**: `POST`

* **请求体**:

  ```json
  {
    "record_id": "uuid",
    "audio_url": "https://example.com/audio.mp3"
  }
  ```

* **响应**:

  ```json
  {
    "task_id": "transcribe_task_uuid",
    "status": "in_progress"
  }
  ```

##### 4.3.2 查询转写状态

* **URL**: `/api/transcribe/{task_id}`

* **方法**: `GET`

* **响应**:

  ```json
  {
    "task_id": "transcribe_task_uuid",
    "status": "completed",
    "text": "转写的文字内容",
    "record_id": "uuid"
  }
  ```

##### 4.3.3 获取转写结果

* **URL**: `/api/records/{record_id}/transcription`

* **方法**: `GET`

* **响应**:

  ```json
  {
    "record_id": "uuid",
    "text": "转写的文字内容",
    "status": "completed",
    "updated_at": "2025-11-28T10:10:00Z"
  }
  ```

#### 5.2 核心流程设计

##### 5.2.1 录音上传与存储流程

1. 客户端录制音频
2. 客户端调用 `/api/audio/upload` 上传音频文件
3. 后端将音频文件存储到本地或云存储
4. 后端返回音频URL
5. 客户端调用 `/api/records` 创建录音记录

##### 5.2.2 语音转文字流程

1. 客户端调用 `/api/transcribe` 提交转写任务
2. 后端创建转写任务记录
3. 后端调用OpenAI Whisper API进行语音转文字
4. 后端更新录音记录的转写状态
5. 客户端轮询 `/api/transcribe/{task_id}` 或 `/api/records/{record_id}` 获取转写结果
6. 转写完成后，后端更新录音记录的text字段

## 接口文档规范

所有API接口遵循RESTful设计原则，使用JSON格式进行数据交互。API响应包含以下标准字段：

* `success`: 布尔值，表示请求是否成功

* `data`: 响应数据

* `message`: 错误或成功消息

* `error_code`: 错误代码（仅在失败时返回）

例如：

```json
{
  "success": true,
  "data": { "id": "uuid", "title": "录音标题" },
  "message": "操作成功"
}

{
  "success": false,
  "message": "录音不存在",
  "error_code": "RECORD_NOT_FOUND"
}
```
